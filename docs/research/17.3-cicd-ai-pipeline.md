# §17.2/§17.3 CI/CD + AI-assisted development pipeline — research report

**Research date:** 26 July 2026 (live web verification). Platform decided: GitHub + GitHub Actions. Solo developer + Claude Code; pipeline substitutes for second reviewer (OPS-1, DEV-3, DEV-4, OPS-3, OPS-4).

## Executive decisions (summary)

| Area | Recommendation | Est. monthly cost |
|---|---|---|
| AI review | `anthropics/claude-code-action@v1` (self-run, API-billed) — general pass on every PR + separate security pass on path-filtered changes | ~US$10–40 in API tokens |
| Security scanning | Dependabot (free) + Semgrep AppSec Platform free tier + Trivy + Gitleaks + GitHub **Secret Protection** SKU ($19) | US$0–19 |
| Deploy target | **Google Cloud Run** (App Runner now in maintenance mode — eliminated) | infra only |
| Rollback | Cloud Run revisions + tagged-revision smoke test before traffic shift; `gcloud run services update-traffic` rollback step | $0 |
| Migrations | Flyway (Kotlin) / golang-migrate (Go), forward-only, run as a gated job **before** traffic shift | $0 |
| Previews | Per-PR Cloud Run service (`--tag pr-123 --no-traffic`) + **Neon branch DB** (Sydney region confirmed) | ~US$0–19 (Neon Launch) |
| IaC | **OpenTofu** + **GCS state backend** (native locking, no SaaS dependency) | ~$0 |
| AI ops triage | Sentry (free/Team) webhooks → `repository_dispatch` → Claude triage workflow. Defer Seer ($40/contributor/mo) and PagerDuty/incident.io AI (enterprise-priced) | ~US$0–26 |

Total pipeline overhead for a solo dev: roughly **US$30–100/month** on top of infra, dominated by AI review tokens.

## 1. AI code review on GitHub (DEV-3)

### Option A — Anthropic managed "Code Review" (claude.ai)
Fully managed multi-agent Code Review service: GitHub App, reviews on PR open / push / `@claude review`, inline severity-tagged comments, false-positive verification pass, `REVIEW.md` repo policy, machine-readable severity JSON gateable in CI. **But**: research preview, **Team/Enterprise Claude plans only**, averages **$15–25 per review**. ([code.claude.com/docs/en/code-review](https://code.claude.com/docs/en/code-review)) Unavailable/overpriced for solo.

### Option B — `anthropics/claude-code-action@v1` (recommended)
GA. Key facts ([repo docs](https://github.com/anthropics/claude-code-action/blob/main/docs/usage.md)):
- Auth: `anthropic_api_key`, `claude_code_oauth_token` (consumes Pro/Max budget), or **Anthropic workload identity federation** via GitHub OIDC — no long-lived key. Also Bedrock/Vertex.
- Review mode: trigger on `pull_request: [opened, synchronize]` with a `prompt`; supports inline comments, `use_sticky_comment`, `include_fix_links`, `track_progress`, `claude_args` (`--max-turns`, `--model`, `--allowedTools`, `--json-schema`).
- Cost: API token billing (Sonnet-class $3/$15 per Mtok, intro $2/$10 through Aug 2026). Typical PR review: cents-to-a-dollar. Budget ~$10–40/mo at solo velocity.

**Security-focused pass on sensitive paths:** no built-in path filter — do it at workflow level. Two workflows:
1. `pr-review.yml` — every PR, general correctness prompt, Sonnet, `--max-turns 10`.
2. `pr-security-review.yml` — `paths:` filtered to auth/sync/row-scoping/evidence/migrations modules, stronger model (Opus-class), OWASP-style checklist prompt: authz on every route, tenant/row-scoping on every query, evidence-chain integrity, secrets in logs, migration hazards. Claude Code also ships `/security-review`.

Keep review policy in-repo (`CLAUDE.md` + `REVIEW.md`-style prompt file) — satisfies OPS-4.

### Option C — GitHub Copilot code review (complement, optional)
GA; agentic review March 2026. Pro ($10/mo) has limited review; auto-review policies need Business ($19/user/mo). Since June 2026 review consumes Actions minutes/AI credits. Reviewer diversity has value; skip if budget tight.

**Recommendation:** Option B, two workflows, WIF auth. General pass non-blocking; security workflow emits structured `{blocking: bool}` verdict that IS a required check on sensitive paths.

## 2. Security scanning stack (private repo, solo dev)

**GHAS state, verified:** since April 2025 GHAS is split into two SKUs, available down to Team plan ($4/user/mo): **Secret Protection $19/active committer/mo** (secret scanning + push protection) and **Code Security $30/active committer/mo** (CodeQL, dependency review, campaigns); $49 combined. Billed on unique active committers — solo dev = 1. ([github.blog changelog](https://github.blog/changelog/2025-03-04-introducing-github-secret-protection-and-github-code-security/))

**Free on private repos:** Dependabot alerts + updates, dependency graph. **Requires Code Security:** CodeQL, `dependency-review-action`.

**Semgrep, verified:** CE free forever; **AppSec Platform free tier includes Semgrep Code (cross-file SAST + Pro rules), Supply Chain (SCA w/ reachability) and Secrets for up to 10 contributors / 10 private repos** ([semgrep.dev/pricing](https://semgrep.dev/pricing/)). Remarkably good fit for one person.

**Recommended stack (≈$19/mo):**

| Layer | Tool | Cost |
|---|---|---|
| Dependency alerts/updates | Dependabot (grouped updates) | Free |
| SAST | Semgrep AppSec Platform free tier (Kotlin/Go/TS supported), `semgrep ci` + SARIF upload | Free |
| Secrets — pre-receive | GitHub **Secret Protection** (server-side push protection); fallback: Gitleaks in CI | $19 or $0 |
| Container + IaC scan | Trivy: image CVEs, misconfig, **SBOM generation** (CycloneDX) per release | Free |
| SBOM/signing | Trivy SBOM artifact + `cosign` keyless signing (OIDC) | Free |
| Dependency-diff on PR | Semgrep Supply Chain + Dependabot cover it | Free |

**Skip CodeQL/Code Security ($30/mo)** at v1 — Semgrep cross-file + AI security review covers the need at $0. Revisit if compliance customers ask for CodeQL by name.

## 3. Deploy automation (OPS-1)

**Target: Cloud Run.** Decisive news: **AWS App Runner entered maintenance mode 31 March 2026, stops accepting new customers 30 April 2026** (migration path: ECS Express Mode) — eliminated. ([InfoQ](https://www.infoq.com/news/2026/04/aws-deprecates-workmail-apprunne/), [encore.dev](https://encore.dev/articles/end-of-app-runner)) Fly.io fine but weaker managed Postgres/IAM; Cloud Run + `australia-southeast1` is the default.

**Auth — no long-lived keys:** `google-github-actions/auth@v3` with **Direct Workload Identity Federation**, `permissions: id-token: write`, provider condition pinned to the repo. Then `deploy-cloudrun@v2`.

**Rollback pattern (native, no extra tooling):**
1. Build image → Artifact Registry (tag = git SHA).
2. **Run migrations first** (see below).
3. `gcloud run deploy --no-traffic --tag candidate` → tagged URL, 0% traffic. Startup/liveness probes must pass.
4. Smoke test hits `https://candidate---svc-xxx.run.app/healthz` + golden paths.
5. On green: `update-traffic --to-latest` (or staged 50→100 with error-rate check).
6. **Automated rollback:** on failure, `update-traffic --to-revisions PRIOR=100` — seconds, since prior revisions stay warm-startable. ([Cloud Run rollouts docs](https://docs.cloud.google.com/run/docs/rollouts-rollbacks-traffic-migration)) A 30-line workflow beats the experimental release-manager tooling.

**Migration ordering (forward-only):** run Flyway/golang-migrate as a dedicated Cloud Run Job in the VPC (CI never needs DB ingress) after image build, before the no-traffic deploy. Every migration must be backward-compatible with the *previous* app revision (expand/contract), because rollback rolls back code, never schema. Enforce in the AI security review prompt: "flag any migration that drops/renames a column still referenced by the current release."

## 4. Preview environments (DEV-4)

**Neon, verified:** Databricks acquisition closed May 2025; Neon continues standalone. Post-acquisition changes *favourable*: compute cut 15–25%, storage $1.75 → **$0.35/GB-month**, free plan 100 CU-hours/mo. **Sydney (`aws-ap-southeast-2`) supported for new projects.** ([neon.com/docs/introduction/regions](https://neon.com/docs/introduction/regions))

**Recommended v1:**
- Per-PR **backend** preview: Cloud Run service `crewcomp-pr-<n>` (scale-to-zero → effectively free), torn down on PR close.
- Per-PR **DB**: `neonctl branches create --parent staging pr-<n>` — copy-on-write branch in seconds; migrate against it; delete on close. The killer feature Cloud SQL can't match (clones slow, billed as full instances).
- Admin SPA preview: served from the preview Cloud Run service. Skip Vercel/Netlify.
- **Trade-off:** Neon runs on AWS Sydney, Cloud Run in GCP Sydney — cross-cloud latency ~1–5 ms + egress. Fine for previews/staging. **Decision point:** Neon for *everything* incl. prod (Launch ~$19/mo, excellent PITR) and accept cross-cloud, or Cloud SQL for prod (~US$15–50/mo small instance) and Neon for previews/staging only.
- Mobile previews: EAS internal-distribution builds only when `mobile/**` changes.

## 5. IaC

Verified current state:
- Terraform remains **BSL 1.1** under IBM (acquisition closed Feb 2025).
- **OpenTofu**: MPL-2.0, Linux Foundation, full provider compatibility, meaningfully diverging with extra CLI features (native state encryption). Lower-risk default for 2026 greenfield.
- **HCP Terraform legacy Free plan EOL 31 March 2026**; replaced by PAYG tier (500 managed resources free) — another SaaS coupling to IBM.
- Pulumi: fine, but general-purpose-language IaC adds test surface for one person.

**Recommendation:** **OpenTofu + GCS state backend** (versioned bucket, native locking, costs cents). `tofu plan` on PRs touching `infra/**` (posted as comment), `tofu apply` on merge via the same WIF identity. Everything in `/infra`: Cloud Run services, Neon (Terraform provider exists), Artifact Registry, monitoring dashboards + alert policies, uptime checks — satisfying OPS-4. Runbooks as markdown in `/runbooks` (consumed by the triage bot).

## 6. AI ops triage (OPS-3)

Verified options:
- **Sentry Seer**: $40/active contributor/mo; issue autofix, delegation to coding agents. ([Sentry pricing](https://sentry.zendesk.com/hc/en-us/articles/45551407771931), [docs](https://docs.sentry.io/product/ai-in-sentry/seer/))
- **PagerDuty SRE Agent**: Advance from $415/mo, AIOps $699/mo — enterprise-priced.
- **incident.io AI SRE**: ~$900/mo flat — not solo-dev economics.

**Pragmatic v1 — build on infrastructure you already have:**
1. Sentry (free/Team ~$26/mo) + Cloud Monitoring alerts + failed Actions runs fan into one entry point: webhook → tiny Cloud Run "webhook-to-dispatch" function → `repository_dispatch` event `ops-triage`.
2. `ops-triage.yml` runs `claude-code-action@v1` with `--allowedTools` limited to read-only `gcloud logging read`, `gh run view`, Sentry API (read), plus `/runbooks/**`. Prompt: read the alert, pull last 30 min of logs, match against runbooks, then (a) open a triage issue with root-cause hypothesis, (b) comment a remediation plan, or (c) for whitelisted auto-remediations (restart job, rerun sync, roll back traffic) invoke the corresponding `workflow_dispatch`. Escalation = push notification (ntfy/Pushover/Slack) when confidence low or action not whitelisted.
3. Structured output (`severity`, `hypothesis`, `action_taken`, `escalate`) keeps it auditable.

<$10/mo in tokens, runbook loop in-repo (OPS-4); Seer layerable later ($40/mo at 1 contributor).

## 7. Proposed pipeline (concrete)

Monorepo: `/backend`, `/admin-web`, `/mobile`, `/infra`, `/db/migrations`, `/runbooks`, `/docs/spec`, `/.github/workflows`. GitHub Team plan ($4/mo, needed for Secret Protection) + Secret Protection ($19). Actions: 3,000 free min/mo on Team.

**`ci.yml`** — `on: pull_request` + `push: branches [main]`
- `changes` (dorny/paths-filter → backend/web/mobile/infra outputs)
- `backend-build-test` — build, unit + Testcontainers-Postgres integration tests, coverage
- `web-build-test` — pnpm build, vitest, tsc
- `semgrep` — `semgrep ci` (SARIF upload)
- `gitleaks` — belt-and-braces secret scan of the diff
- `migrations-check` — apply full migration chain to fresh Postgres container; fail on checksum/ordering violations
- `docker-build` + `trivy-scan` (image CVE + SBOM artifact) — on backend changes
- `tofu-plan` — on `infra/**` changes, plan posted as PR comment

**`pr-review.yml`** — every PR: `claude-code-action@v1`, WIF auth, general correctness prompt from `/.github/review-prompt.md`, sticky comment + inline findings. Non-blocking.

**`pr-security-review.yml`** — `paths:` for auth/sync/row-scoping/evidence/migrations: Opus-class model, security checklist, structured output `{blocking, findings[]}`; job fails if `blocking` → **required status check** on those paths.

**`preview.yml`** — backend-path PRs: `neon-branch` (create/reset `pr-<n>` from staging) → `migrate` → `deploy-preview` (Cloud Run, scale-to-zero) → sticky comment with URLs.
**`preview-teardown.yml`** — PR close: delete service + Neon branch.

**`deploy-staging.yml`** — push to main (after CI green): `build-push` (SHA-tagged, cosign-signed) → `migrate-staging` (Cloud Run Job) → `deploy` (`--no-traffic --tag candidate`) → `smoke` → `shift-traffic` (or fail→rollback) → `e2e-staging` (Playwright against admin SPA). Green staging auto-creates a prod release candidate (tag `rc-<sha>`).

**`deploy-prod.yml`** — tags `v*` + auto-trigger from green staging, no manual steps (OPS-1): migrate → no-traffic deploy → smoke → 50% → 5-min Cloud Monitoring error-rate/latency gate → 100%; any gate failure runs `update-traffic --to-revisions PRIOR=100` and files an `ops-triage` dispatch. GitHub Environment `production` records deploys; no approval gate (security review + staging E2E are the gate).

**`mobile.yml`** — main pushes on `mobile/**` + tags `mobile-v*`: PR analyze/test only; main → EAS Build internal distribution (free tier: 15 iOS + 15 Android builds/mo); tag → EAS Submit to TestFlight/Play internal. (Adjust to Codemagic/fastlane if Flutter wins mobile.)

**`ops-triage.yml`** — `repository_dispatch [ops-triage]` + `workflow_run [deploy-*: failure]` — the §6 triage bot.

**Nightly (`scheduled.yml`):**
- `deps` — auto-merge patch-level green Dependabot PRs (`gh pr merge --auto` when all checks incl. AI review pass)
- `backup-verify` — restore latest PITR point into a throwaway branch/instance, run row-count/checksum assertions, report to triage on failure — the compliance-product credibility check
- `claude-nightly-audit` (weekly) — Claude Code pass over open Sentry issues + TODOs, files prioritized issues.
